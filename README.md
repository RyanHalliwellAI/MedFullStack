# Medical Platform Full Stack Application

## Overview
A small, responsive, full-stack medical platform designed for seamless patient booking and clinic management. Engineered using **React, JavaScript, HTML, C#, .NET, and SQL**.

* **System Architecture:** Leveraged APIs to smoothly connect the user interface with internal backend systems, ensuring seamless handling of user interactions.
* **Database Integration:** Utilized a SQL database to efficiently handle and secure user authentication, manage appointment scheduling, and facilitate administrative actions while maintaining data integrity.
